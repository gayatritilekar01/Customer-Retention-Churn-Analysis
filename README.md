# Customer Retention & Churn Analysis

## About the Project

This project is about understanding customer churn and retention using Power BI. The analysis looks at customer data to find out which types of customers are more likely to leave the service.

The dashboard presents the main churn patterns in a simple and easy-to-understand way.

## Project Objective

The main objective of this project is to:

- Understand the overall customer churn rate
- Find customer groups with higher churn
- Compare churn across different contract types
- Analyze churn by payment method
- Compare churn across internet service types
- Understand how customer tenure is related to churn
- Suggest ways to improve customer retention

## Tools Used

- Power BI
- Excel
- Data Analysis
- Data Visualization

## Dashboard

The Power BI dashboard includes:

- Total Customers
- Churned Customers
- Overall Churn Rate
- Churn by Payment Method
- Churn by Contract Type
- Churn Rate by Internet Service
- Churn Rate by Tenure Group

## Key Insights

- The overall customer churn rate is 26.54%.
- Around 2K customers have churned out of approximately 7K customers.
- Month-to-month customers show higher churn compared with longer-term contract customers.
- Customers with lower tenure are more likely to leave the service.
- Churn rates are different across internet service types and payment methods.

## Recommendations

Based on the analysis, businesses can focus more on customers who are at higher risk of leaving.

Some possible actions are:

- Encourage month-to-month customers to choose longer-term plans.
- Improve onboarding and support for new customers.
- Provide loyalty benefits to retain existing customers.
- Identify high-risk customer groups and offer them suitable retention offers.
